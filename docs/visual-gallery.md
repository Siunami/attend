# Attend visual gallery

Every label and value in these screenshots is fabricated demo data. No user files, accounts, or private sources were used to make them. The images can be used as full-resolution case-study figures.

Select any image to open its full-resolution PNG.

## Distribution

Reveal shape, spread, gaps, and outliers in a measure.

[![A distribution plot comparing fabricated session lengths across three kinds of work](images/visual-gallery/distribution.png)](images/visual-gallery/distribution.png)

## Trend

Show how a measure changes over time and make turning points visible.

[![A line chart showing a synthetic weekly trend](images/visual-gallery/trend.png)](images/visual-gallery/trend.png)

## Network

Inspect connections and identify the strongest bridges between entities.

[![A network diagram connecting fabricated concepts in a generic project](images/visual-gallery/network.png)](images/visual-gallery/network.png)

## Flow

Trace movement, loss, and conversion through a process.

[![A flow diagram tracing where synthetic projects are lost between pipeline stages](images/visual-gallery/flow.png)](images/visual-gallery/flow.png)

## Field

Show intensity across constructed space, such as weekdays and times.

[![A field heatmap showing fabricated attention values by weekday and time](images/visual-gallery/field.png)](images/visual-gallery/field.png)

## Collection atlas

Browse a collection without flattening it into a single score.
